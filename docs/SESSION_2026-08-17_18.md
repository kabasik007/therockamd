## Stale process / duplicate instance

Closing the visible CMD did not reliably terminate the ComfyUI Python process.

A later launch produced:

```text
Could not acquire lock on database ...\user\comfyui.db
Port 8188 is already in use on address 127.0.0.1
```

These are two symptoms of the same stale/duplicate process problem.

Required design:

- `STOP_COMFYUI.bat` for reliable process-tree termination;
- exact-process validation before `taskkill /T /F`;
- launch preflight refusing to start while port 8188 is occupied.

## VAE workflow mistake

The workflow's `Load VAE` was accidentally set to:

```text
pixel_space
```

Then ComfyUI reported:

```text
Requested to load PixelspaceConversionVAE
Cannot handle this data type: (1, 1, 16), |u1
```

The error happened in Pillow `Image.fromarray` inside `SaveImage`.

Root cause: sampled latent data was not being decoded by the real Z-Image VAE before save.

Fix:

```text
Load VAE = ae.safetensors
```
